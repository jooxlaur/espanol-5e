# Español 5e

Outil gratuit pour accompagner un élève de 5e en espagnol : comprendre la construction des phrases
(verbes encadrés, mots-questions soulignés, petits mots entourés), apprendre le vocabulaire petit à petit,
et s’entraîner. Marche sans internet une fois installé, sans compte, sans publicité.

**Ouvrir l’appli :** https://jooxlaur.github.io/espanol-5e/

Aucune donnée n’est envoyée : tout reste sur l’appareil qui utilise l’appli.
